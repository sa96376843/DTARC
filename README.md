# DTARC：实验代码与冻结汇总结果

Drift-Type-Aware Replay with Consistency (DTARC) 研究延迟反馈下的漂移检测与经验回放。本仓库公开作者提供的实验代码快照、依赖、数据来源说明及聚合结果，供同行检查实现与已报告数字。

**当前版本仍是研究快照。** 2026-10-30 已修复主数据面板替换后摘要未刷新的流程错误：`prepare_robustness_data.py` 现在在所有面板生成后，从最终 CN/TH 主面板重新计算摘要。完整本地包重新执行数据阶段和原最终校验均通过；哈希确认本次修复没有改变数据 CSV、预测、实验指标或图件，也没有重训。训练与评价算法及冻结汇总结果保持原样，其他已确认问题见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。此前重跑仍未严格匹配原冻结神经模型结果，不能将此次流程修复视为数值复现完成。

## 内容

- `src/`：20 个 Python 脚本（其中 1 个含上述元数据同步补丁），包括下载、预处理、实验、统计、回测和图表构建代码。
- `results/`：按种子/方法汇总的预测指标、更新次数与运行时间、bootstrap、消融和经济指标；保留负结果。
- `data/dataset_summary.json`：特征名、样本规模和时间划分元数据。
- `requirements*.txt`、`ENVIRONMENT.txt`：原实验依赖与环境记录。
- `DATA_SOURCES.md`：上游行情来源及本地完整包采用的文件命名。所列行情快照**不包含在这个公开仓库**。
- `SOURCE_MANIFEST.json`：逐文件大小和 SHA-256；`verify_public.py` 校验发布文件完整性。

## 使用

无需安装机器学习依赖即可检查发布文件是否完整：

```bash
python verify_public.py
```

查阅 `results/metrics_h5.csv`、`results/best_config.json` 和统计结果不需要行情文件。若自行合法取得兼容的数据并按来源说明配置完整的 `data/`，可安装依赖并使用源脚本：

```bash
python -m pip install -r requirements.txt
python src/validate_reproduction.py
```

第二条命令检查的是完整本地包所需的行情、冻结逐行预测和历史图件；本公开子集没有这些文件，因此直接运行会明确报缺失，不能以公开子集运行成功替代完整数据复现。

原 `run_pipeline.py --stage experiments` 会重新调参和训练并覆盖结果；`--stage artifacts` 依赖完整数据/预测/历史稿件材料，且会生成旧稿结构。不要在唯一的冻结副本或当前论文目录上执行。先阅读代码、解决已知问题、准备独立输出目录，再制定并执行复现实验。

## 数据与发布范围

公开仓库未重新分发 Sina、SiamChart、BaoStock 行情快照、处理后逐日面板、可还原逐股收益的预测文件、逐日经济曲线、第三方网页和论文全文。数据可公开访问不自动代表可再分发；请从合法来源取得数据并遵守适用条款。现有汇总结果不能代替逐行数据，也不能保证未来重新下载的快照相同。

本地核验曾从 169,440 行冻结预测重新计算 80 行主指标，最大误差小于 1e-15；这是指标算术一致性核对，**不是重新训练验证**。已报告结果未建立 DTARC 相对均匀 ADWIN 回放、静态模型或线性挑战者的普遍优势。

本仓库未新增开源许可证；公开访问不等于授予未声明的再许可权利。第三方数据与软件依其各自条款使用。
